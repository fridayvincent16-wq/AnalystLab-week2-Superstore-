Superstore Sales Analysis Dashboard

📊 Project Overview

This project was completed as part of my Week 2 Data Analytics Internship Assignment at AnalystLab Africa.

The project focused on analyzing the Superstore dataset and developing an interactive Power BI dashboard to uncover insights into sales, profit, customers, products, and regional performance.

🎯 Objectives

* Analyze overall sales and profit performance.
* Identify top-performing product categories and sub-categories.
* Analyze sales and profit trends over time.
* Identify top-performing products and regions.
* Analyze customer segment performance.
* Provide an interactive dashboard for better business decision-making.

🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Visualization
* Data Cleaning & Transformation

📌 Analysis Areas

The dashboard analyzes:

* Sales Performance
* Profitability
* Product Categories
* Sub-Categories
* Customer Segments
* Regional Performance
* Sales Trends
* Profit Trends
* Top 10 Products
* Geographical Performance

📈 Dashboard

The Power BI dashboard provides an interactive view of the Superstore dataset. Users can explore the data using interactive visuals, filters, and slicers to identify trends and patterns in business performance.

💡 Key Insights

The analysis provides insights into:

* The highest-performing product categories and sub-categories.
* Products and regions contributing significantly to sales and profit.
* Changes in sales and profit over time.
* Customer segments with strong business performance.
* Areas where profitability and overall performance can be improved.
